# Aiko Desktop Pet

**Aiko ist die Chibi-Personifizierung deines Rechners.** Sie lebt an der Windows-Taskleiste, hat Bedürfnisse, reagiert auf Rechnerlast und erzählt kurze, charaktergerechte Dialoge mit Kenney-Emotes.

**Stand:** v0.13 (Python 3.11+, Windows 10/11). Der vollständige, getestete Projektstand ist für den ersten Quellcode-Import vorbereitet; die Dateien sind in diesem Repository derzeit noch nicht vollständig hochgeladen.

Die erste Veröffentlichung erfolgt ohne Überschreiben der bestehenden Git-Historie. Danach sind Startdateien, alle 73 Originalsprites, 15 Kenney-Emotes, Tests, Vorschauen und GitHub Actions hier verfügbar.

**Lizenzen:** Der Programmcode steht unter [MIT](LICENSE). Für eigene Aiko-Grafiken und Kenney-Assets gelten unterschiedliche Rechte: [ASSETS.md](ASSETS.md). Eine externe KI-API wird nicht benötigt.
