# Twemoji game hand artwork — CC BY 4.0

**Attribution:** Twemoji by Twitter and contributors,
[Twemoji GitHub repository](https://github.com/jdecked/twemoji).

Aiko Desktop Pet incorporates three light-skin-tone hand illustrations from
the upstream Twemoji `assets/svg/` directory:

- `270a-1f3fb.svg` → `aiko_pet/assets/game_hands/rock.png`
- `270b-1f3fb.svg` → `aiko_pet/assets/game_hands/paper.png`
- `270c-1f3fb.svg` → `aiko_pet/assets/game_hands/scissors.png`

**Changes:** Each vector image was rasterized at 72 × 72 pixels, palette
optimized and saved as transparent PNG. The intended emoji/hand gesture
was not changed.
